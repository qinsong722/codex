# 批车单自动审批

## 首次使用

1. 安装依赖：

```bat
python -m pip install -r requirements.txt
```

2. 启动脚本：

```bat
start_approval.bat
```

## 使用方式

1. 脚本会打开 Edge，并自动填写手机号 `13922200297`。
2. 脚本会自动勾选协议并点击“获取验证码”。
3. 你在浏览器里输入验证码并点击“登录”。
4. 登录后脚本会直接进入“申请单审批”页面并开始循环审批。
5. 如果点击“同意”后出现提交人选择页，脚本会选择“覃嵩”再提交。
6. 如果当前没有待审批申请单，脚本会停留在当前审批页面，每 5 分钟自动刷新一次并重新检查。

## 说明

- 浏览器默认不会自动关闭，会持续停留在审批页面值守。
- 脚本会一直运行，直到你手动关闭脚本进程或关闭浏览器。
- 站点是单页应用，页面结构如果后续变动，可能需要更新选择器。
- 目前脚本按你给的规则优先走 `#/audit` 路由，不再依赖首页手动点菜单。
