# 跑酷抓老鼠游戏设计说明

**日期：** 2026-03-18

## 目标

把当前的“小猫选盒子”原型改成一个更像跑酷小游戏的新版本。

玩家控制一只猫在场景中持续向右跑动，用鼠标调整左右位置，并通过点击让猫跳起来。前方会不断出现高低不同的盒子，部分盒子上有不同等级的老鼠。猫碰到老鼠后，按等级判断是否能抓到；抓到则成长，抓不到则掉生命。界面右上角支持中英文切换。

## 核心玩法

### 1. 基本操作

- 猫持续向右移动
- 鼠标左右移动时，猫也会左右微调位置
- 鼠标点击时，猫跳起

### 2. 场景结构

- 地图持续向前展开
- 前方会生成高低不同的盒子
- 有些盒子上会站着老鼠
- 猫可以跳到盒子上，也可能从盒子间掉落

### 3. 老鼠与等级

- 每只老鼠有等级
- 猫也有自己的等级
- 当猫碰到老鼠时：
  - 如果猫等级大于或等于老鼠等级，抓到老鼠
  - 如果老鼠等级高于猫，猫掉生命

### 4. 成长与失败

- 猫抓到老鼠后获得成长
- 成长累积后升级
- 等级提高后，猫的外观阶段变化
- 如果猫从盒子上掉落，也扣 1 点生命
- 扣血后猫回到地面继续跑
- 生命归零时，本局结束

## 第一版范围

第一版只做最关键、最可玩的内容：

- 持续跑动
- 鼠标左右控制
- 鼠标点击跳跃
- 高低不同的盒子平台
- 固定站在盒子上的老鼠
- 等级判断
- 生命值系统
- 猫成长升级
- 中英文切换按钮

第一版先不做：

- 技能系统
- 多地图主题
- 音效和背景音乐的完整打磨
- 老鼠复杂移动逻辑
- 猫品种分支树
- 暂停菜单和设置页

## 界面设计

### 主界面

- 中间是主游戏区域
- 左上或上方显示：
  - 猫等级
  - 当前生命
  - 已抓老鼠数量
  - 成长进度
- 右上角放语言切换按钮

### 语言切换

- 右上角一个按钮
- 支持 `中文 / English`
- 切换后，界面文本立即变化

## 交互节奏

推荐第一版节奏：

- 前期盒子较低、间距较小
- 前期老鼠等级偏低，让玩家更容易抓到并成长
- 中后期逐渐增加盒子高度变化和老鼠等级压力

## 技术实现建议

延续当前技术栈：

- Vite
- Electron
- HTML / CSS / JavaScript

原因：

- 当前项目已经在这个方向上运行
- 更适合快速迭代 2D 小游戏原型
- 做中英切换、界面动画和碰撞反馈都比较方便

## 模块拆分建议

建议把新版本拆成这些职责：

- `game loop`：持续更新猫、盒子、老鼠和碰撞
- `input`：处理鼠标移动和点击跳跃
- `world generation`：生成不同高度的盒子和老鼠
- `rules`：等级比较、掉血、成长、升级
- `i18n`：处理中英文文本
- `render`：渲染游戏界面和 HUD

## 测试重点

第一版至少验证这些行为：

- 鼠标点击会触发跳跃
- 猫抓到低等级老鼠时能成长
- 猫碰到高等级老鼠时掉生命
- 猫掉下平台时掉生命并回到地面
- 生命归零时触发游戏结束
- 语言切换后界面文字正确变化

## 风险与取舍

这次改动属于玩法重构，不是简单换皮。

主要风险：

- 需要把当前“回合式点击盒子”结构改成“持续更新的跑酷循环”
- 跳跃手感如果没调好，游戏会不好玩
- 鼠标左右控制和自动向右推进之间要平衡，不然会显得别扭

第一版的取舍是：

- 先用简单图形和现有卡通样式完成可玩性
- 先把跑、跳、碰撞、成长、中英切换做稳
- 等核心手感成立后，再做更细的美术和动画
